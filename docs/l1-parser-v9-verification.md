# Parser 9 local verification

October 9–10, 2026 (Europe/Berlin). Baseline: `9a16d25d` (parser 8). Implemented stack: parser **9**, usage extraction **5**, usage identity **1**, attestation **v3**, run-index **2**. This is local literal-evidence verification, not a production deployment or a writer-semantics certification.

## Method and limits

- Read only `~/.claude/projects/**/*.jsonl` and `~/.codex/sessions/**/*.jsonl`; no network, database, production, Rust build, package installation, or local Claude Code source tree access.
- One corpus audit at a time. Each file is read through a 64 KiB stream and JSON is decoded one line at a time. File byte sizes are captured once and reused by the outcome prepass and source/parser pass; later appends are not mixed into a generation. State is bounded to per-file parser correlation, parent IDs/call IDs, per-call outcomes and integer counters; there is no whole-file buffering or corpus-wide row array.
- Execute the actual agent adapters, literal Codex outcome prepass and session `budgetFacts`; compare with parser-8 adapters from a `git archive` of the baseline (a temporary source snapshot, not another worktree). Source presence is counted independently through `censusRecordPaths`. Identities/offsets are covered by the v5 identity test, not regenerated by this counter-only audit.
- Resolve fork parents by explicit session IDs and actual root call IDs, one parent at a time. The primary audit collected response-item call IDs; a sequential supplemental audit then proved native completion-only call IDs through the actual parent adapters, matching production's parent `tool_call` query. No clock/subagent-parent heuristic. Raw replay rows stay marked; interpretation excludes them.
- Run-index failure/refusal/edit tallies below are counter equivalents of the SQL's predicates, not executed ClickHouse queries. The read/search disagreement audit uses a simplified first-command classifier; it is a local mismatch census, not a replay of every legacy SQL heuristic. Unit tests check the exact SQL override and version gates.
