# Team invitation social card assets

- `InterVariable.ttf` is Inter 4.1 from https://github.com/rsms/inter/tree/v4.1/docs/font-files, distributed with its included SIL Open Font License.
- `opaline-wordmark.svg` is the existing Opaline navigation wordmark from the marketing app.

The API uses these bundled assets to render the invitation PNG without remote font or image requests.
